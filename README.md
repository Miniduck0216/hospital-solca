# Hospital SOLCA · orientación interior

Prototipo académico de orientación dentro de un hospital (mapa 2D tipo kiosco y recorrido 3D, rutas con A*).
La silueta, los accesos y el entorno se toman del mapa real de SOLCA Quito. La distribución interior es una **propuesta** y no corresponde a los planos reales del hospital.

- Sitio: https://miniduck0216.github.io/hospital-solca/
- Desarrollo: `npm install` y luego `npm run dev`
- Publicación: cada `push` a `main` construye el sitio y lo publica en GitHub Pages (`.github/workflows/pages.yml`).
